# Authentication mockup prompts

Reference for both: `../concepts/04-refined-hybrid.png` (actual selected hybrid attached to each built-in ImageGen call).

These are page studies within the chosen direction, not new alternatives. Generated UI copy and shapes are design references; implementation uses real controls, existing auth APIs, and shared brand assets.

## Sign in

```text
Use case: ui-mockup
Asset type: RUSHES desktop sign-in screen, high-fidelity product design, 1440 by 1000.
Primary request: Extend the attached selected RUSHES refined hybrid into its separate SIGN IN page. This is the same product and design direction, not another alternative.
Input images: Image 1 is the authoritative visual reference for light palette, typography, bespoke cut-shaped R mark, lowercase rushes wordmark, whitespace and blue accent. Preserve its regular, light editorial sans typography. Keep heading unbolded.
Composition/framing: Full clean off-white desktop page. Header at 64px from either side: reference logo and wordmark at left; compact sun icon, Light label, chevron at right. Below, center one 400px-wide form with generous empty space, no photograph, no illustration, no enclosing card, no sidebar. Form begins around x520 y220. One regular 44px heading, one quiet supporting line, two stacked clearly labeled 54px high inputs, then one blue full-width 54px submit button. Label spacing 10px, fields separated by 24px. Password input includes a restrained eye icon at right. Footer quiet centered links at page bottom.
Text (verbatim): Heading "Welcome back." Supporting text "Sign in to your footage." Fields "Email" and "Password"; blank fields, no personal data. Submit "Sign in" with a thin arrow to its right. Below form "New to RUSHES? Create an account" with linked final words. Footer "Privacy" and "Terms". Header appearance "Light".
Color palette: warm near-white background, nearly black text, muted gray secondary copy, delicate gray input borders, source-reference saturated clean blue CTA, white button label.
Constraints: Refine the attached image's clean visual language; simple monochrome R mark and wordmark. Crisp UI text, realistic spacing, semantic forms. Show only these exact functions. No social login, password recovery, decorative badges, slogans, panels, or extra controls. No shadows, gradients, device mockup, photograph or people. No browser chrome.
```
